POST /api/v1/predict

Send a JSON object. Only area is required. Fields not listed below are rejected, so a typo cannot be silently ignored.

FieldTypeMeaning
areanumberPlot area, in area_unit. Must convert to {{ options.limits.area_sqyd[0]|num }}–{{ options.limits.area_sqyd[1]|num }} sq yd.
area_unitstringOne of {% for k in options.area_units %}{{ k }}{{ ", " if not loop.last }}{% endfor %}. Default sqyd.
localitystringOne of {% for l in options.localities %}{{ l }}{{ ", " if not loop.last }}{% endfor %}, or {{ options.other_locality }}. Default {{ options.default_locality }}.
facingstringA compass direction such as East or North-East. Optional.
open_sidesinteger1–4. Optional.
road_width_ftnumberWidth of the road in front, in feet ({{ options.limits.road_width_ft[0]|num }}–{{ options.limits.road_width_ft[1]|num }}). Optional.
in_projectbooleanInside a named layout or gated venture. Default false.

Example

curl -X POST {{ request.host_url }}api/v1/predict \
  -H "Content-Type: application/json" \
  -d '{{ example_request }}'

The response holds the estimate and range in rupees (rounded to ₹1,000), the price per sq yd, the normalised input, any warnings, comparable listings (up to 5; one shown here) and the model version. This is the live response from the current model:

Errors

Errors use the matching HTTP status and a JSON body {"error": {"code": ..., "message": ...}}. Validation errors (400) add a fields object that maps each bad field to a message. Other statuses: 415 (not JSON), 413 (body over 16 KB) and 429 (rate limit; see Retry-After).

Other endpoints

  • GET /api/v1/meta: accepted values, limits, the inputs the model uses, and model version.
  • GET /api/v1/health: liveness check for load balancers. Returns {"status": "ok"} and the model version.
